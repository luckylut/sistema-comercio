# Sistema-Comércio

## Descrição
Sistema de gerenciamento para pequenos comerciantes.

## Objetivo
Ajudar comerciantes a organizar produtos, estoque e vendas em um único sistema.

## Funcionalidades
- Cadastro de produtos
- Controle de estoque
- Registro de vendas
- Consulta de informações da loja
- Alertas de estoque baixo

## User Stories
- Como comerciante, quero cadastrar produtos, para manter minha loja organizada.
- Como comerciante, quero consultar o estoque, para saber quais produtos estão disponíveis.
- Como comerciante, quero registrar vendas, para acompanhar as vendas da loja.
- Como comerciante, quero acessar o sistema pelo celular, para acompanhar minha loja.
- Como comerciante, quero receber alertas de estoque baixo, para saber quando repor produtos.
